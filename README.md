# 🛡️ RiskLens

### Personalised Vulnerability Intelligence & AI Security Copilot

RiskLens is a cybersecurity risk-prioritisation platform that helps organisations identify **which vulnerabilities deserve attention first**.

Instead of treating every CVE equally, RiskLens combines vulnerability intelligence with an organisation's **sector, risk appetite, CVSS severity, KEV status, EPSS probability, and contextual risk factors** to produce a prioritised vulnerability list.

It also includes an **AI-powered Security Copilot**, powered by Google's Gemini API, that explains why a vulnerability is prioritised and provides defensive guidance using the actual RiskLens context.

---

## 🚀 Why RiskLens?

Modern organisations may have hundreds or thousands of vulnerabilities.

The problem isn't simply:

> "Which vulnerabilities exist?"

The real question is:

> **"Which vulnerabilities should we deal with first?"**

Traditional vulnerability scanners often produce large lists of CVEs and severity scores.

RiskLens takes a different approach:

```text
Vulnerability Data
        ↓
Organisation Context
        ↓
Risk Scoring
        ↓
CVSS + KEV + EPSS
        ↓
Contextual Prioritisation
        ↓
Top Vulnerabilities
        ↓
AI Security Copilot
